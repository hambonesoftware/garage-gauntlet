# Garage Gauntlet · Railway Rush

[Play Railway Rush](https://hambonesoftware.github.io/garage-gauntlet/)

Drive a miniature RC car through a tabletop model railway town. Race three rivals in Grand Prix or go solo in Time Trial. Recharge on the teal boost pads and watch for the train at both crossings.

Open [UnityGame](UnityGame/README.md) for controls, Unity setup, and GitHub Pages build instructions.
