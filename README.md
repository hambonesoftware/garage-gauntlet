# Garage Gauntlet · Railway Rush

[Play Railway Rush](https://hambonesoftware.github.io/garage-gauntlet/)

Race die-cast slot cars through a model train town. Use the trigger to manage power on four separate lanes, and lift before tight bends and active crossings. Race three rivals in Grand Prix or go solo in Time Trial.

Open [UnityGame](UnityGame/README.md) for controls, Unity setup, and GitHub Pages build instructions.
